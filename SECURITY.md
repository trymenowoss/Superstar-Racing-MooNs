# Security policy

## Reporting a vulnerability

Do not disclose passwords, private infrastructure details, or security vulnerabilities in a public GitHub issue.

Contact the repository owner privately through their GitHub profile with a short description and a safe way to continue the report. Change any exposed game password immediately.

Official private contacts:

- Discord: `@iamsicknow`
- Telegram: `@wanderbotnow`

## Player safety

- Download releases only from this repository.
- Compare the downloaded ZIP's SHA-256 checksum with the checksum published in its GitHub release notes.
- Keep Windows and antivirus security updates current.
- Never share your native game password.
